# Task-5-Exploratory-Data-Analysis-EDA-
# Titanic Dataset - Exploratory Data Analysis (EDA)

## 📊 Overview

This project performs EDA on the Titanic dataset using Python libraries like `pandas`, `matplotlib`, and `seaborn`. It includes data cleaning, visualization, and insights generation.

---

## 🔧 Tools Used
- Python (Jupyter Notebook)
- Pandas
- Matplotlib
- Seaborn

---

## 🧼 Key Steps

1. **Data Loading**  
   Loaded the Titanic dataset from CSV.

2. **Data Cleaning**  
   - Removed duplicates and unnecessary columns.

3. **Exploratory Data Analysis (EDA)**  
   - Univariate, bivariate, and multivariate visualizations.
   - Correlation heatmap and survival analysis.

4. **Insights**  
   - Higher survival rate for females and 1st class.
   - Socioeconomic status influenced survival.
   - Fare positively correlated with survival.

---

## 📁 Files in this Repository

- `titanic_eda.ipynb`: Jupyter notebook with full code.
- `titanic.csv`: Dataset used.
- `report.pdf`: Final insights report with visualizations.
- `README.md`: Project overview and instructions.
